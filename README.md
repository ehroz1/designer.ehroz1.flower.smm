# Ehroz — дизайн под ключ

Одностраничный сайт-предложение: брендинг, сайты, SMM-дизайн и конструктор постов.
Чистый HTML, CSS и JS без сборки и зависимостей, свёрстан в первую очередь под телефон.

## Структура

```
index.html      — весь текст и разметка сайта
css/style.css   — стили и анимации
js/main.js      — интерактив: меню, анимации при прокрутке, демо конструктора, таймер
img/            — фотографии (см. PROMPTS.md)
favicon.svg     — иконка вкладки
PROMPTS.md      — промпты для генерации всех фотографий
```

## Что поменять перед запуском

1. **Контакты.** Откройте `js/main.js`, в самом верху есть блок `CONFIG`:
   ```js
   const CONFIG = {
     telegram: 'Ehroz',   // ник в Telegram без @
     whatsapp: '',        // номер цифрами, например 77001234567
     portfolio: '',       // ссылка на портфолио
     message: 'Дизайн',
   };
   ```
   Пустые поля скрывают соответствующие кнопки, поэтому, пока нет номера WhatsApp, на сайте не будет «мёртвой» кнопки.
2. **Фотографии.** Сгенерируйте их по промптам из `PROMPTS.md` и положите в `img/` с теми же именами.
   До этого на их месте стоят пастельные градиенты.

## Анимации

- Прелоадер с именем и искоркой, плавный выезд заголовка.
- Падающие лепестки на первом экране (canvas, на паузе, когда экран не виден).
- Бегущие строки с направлениями и брендами.
- Текст «Большинство бизнесов…» проявляется по словам при прокрутке.
- Карточки «Знакомо?» складываются в стопку.
- Орбита «5 подрядчиков → 1 дизайнер».
- Живое демо конструктора постов: шаблоны переключаются сами или по нажатию, текст «печатается», кнопка «Скачать» срабатывает.
- Таймер до конца месяца для спецпредложения.
- Линия этапов работы заполняется при прокрутке, звёзды загораются.
- Плавающая кнопка «Написать» на телефоне.

Если в системе включено «Уменьшить движение», анимации отключаются.

## Как открыть сайт по ссылке (GitHub Pages)

1. В репозитории откройте **Settings → Pages**.
2. В **Source** выберите **Deploy from a branch**.
3. Выберите ветку с сайтом и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу вида `https://<логин>.github.io/<репозиторий>/`.

Локально достаточно открыть `index.html` в браузере.
